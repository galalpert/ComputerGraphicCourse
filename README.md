# Computer Graphics Project

I created this project with Daniel Glazman as part of the Computer Gaphics course
we took at University of Haifa during our BS.c in computer science.
The project was written in C++ and OpenGl. 

The progress, Images and the code can be seen in:
Assigment1Report, Assigment2Report and Assigment3Report.

We were given a base code that implemented a simple mesh viewer and our goal was to implement a renderer,
that can render and transform obj mesh models to the screen and implement the scene which include camera, light and more. 
Later on we replaced our implementation with OpenGl code and implemented basic texture features.

Main implementations for our renderer:
- Implement and improve Bresenham's algorithm for drawing lines.
- Loading several mesh models and allowing the user to perform translations using GUI and I/O.
- Implementing a camera that views the scene using different projections: perspective and    orthographic.
- Implementing Edge walking algorithem to fill the meshes tringles and display them as full.-
- Implementing a z-buffer.
- Adding light objects to the scene and implementing Phong shading.
